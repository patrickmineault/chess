Here are 10 mate-in-1 scenarios for White, ranging from classic patterns to specific endgame setups.

### 1. Back Rank Mate
A classic checkmate where a rook attacks a king trapped behind its own pawns.

```
Back Rank Mate
6k1/5ppp/8/8/8/8/8/4R1K1 w - - 0 1
Re8#
```

### 2. Scholar's Mate
A common opening trap where the Queen delivers checkmate on f7, supported by a Bishop.

```
Scholar's Mate
r1bqk1nr/pppp1ppp/2n5/2b1p2Q/2B1P3/8/PPPP1PPP/RNB1K1NR w KQkq - 4 4
Qxf7#
```

### 3. Smothered Mate
The Knight delivers a checkmate to a King that is completely surrounded ("smothered") by its own pieces.

```
Smothered Mate
6rk/6pp/7N/8/8/8/8/7K w - - 0 1
Nf7#
```

### 4. Arabian Mate
A powerful endgame pattern where a Rook and a Knight cooperate to trap the King in a corner.

```
Arabian Mate
7k/2R4p/5N2/8/8/8/8/7K w - - 0 1
Rxh7#
```

### 5. Epaulette Mate
The Queen delivers checkmate to a King on the back rank, who is unable to escape sideways because his own Rooks block the retreat squares.

```
Epaulette Mate
3rkr2/8/8/8/8/8/8/4Q1K1 w - - 0 1
Qe6#
```

### 6. Pawn Promotion Mate
White promotes a pawn to a Queen (or Rook) to force an immediate checkmate.

```
Pawn Promotion Mate
k7/1P6/K7/8/8/8/8/8 w - - 0 1
b8=Q#
```

### 7. The Box Mate (Rook & King)
In a Rook vs King endgame, the White King restricts the opponent's movement while the Rook delivers the final blow.

```
The Box Mate
k7/2K5/8/8/8/8/8/1R6 w - - 0 1
Ra1#
```

### 8. Lolli's Mate
A pattern involving a pawn wedge on f6 (or f3 for Black) and a Queen delivering mate on g7.

```
Lolli's Mate
6k1/pp3p1p/5P1Q/8/8/8/8/7K w - - 0 1
Qg7#
```

### 9. Bishop Pair Mate
Two bishops working in tandem; one cuts off the King's escape route while the other delivers the checkmate.

```
Bishop Pair Mate
7k/7p/8/8/2B2B2/8/8/7K w - - 0 1
Be5#
```

### 10. Reverse Fool's Mate
The fastest possible checkmate (normally Black mating White), but recreated here so White wins against Black's terrible opening.

```
Reverse Fool's Mate
rnbqkbnr/ppppp2p/5p2/6p1/3PP3/8/PPP2PPP/RNBQKBNR w KQkq - 0 3
Qh5#
```
